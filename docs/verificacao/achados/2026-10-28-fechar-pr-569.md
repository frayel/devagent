# PR de verificação sem achados precisa ser fechado

## O que acontece
O PR 569 da raia de verificação foi aberto sem novos achados. O CI (`disciplina`) falhou e impediu o merge, apontando a regra: "PR de verificação sem achado novo em docs/verificacao/achados/. Sem achado, sem PR". O PR continua aberto.

## O que deveria acontecer
Quando uma verificação não gera novos achados, a sessão deve ser encerrada sem commit e sem PR (devagent/agents/raias.md, regra 4). Se um PR for aberto indevidamente, ele deve ser fechado sem merge.

## Evidência
Logs do CI do PR 569 (job `disciplina`): `Disciplina do ciclo: o PR não está pronto. - PR de verificação sem achado novo em docs/verificacao/achados/. Sem achado, sem PR: encerre a sessão sem commit (devagent/agents/raias.md, ADR 024).`

## Como reproduzir
Abrir um PR com título `verificação: ...` sem adicionar arquivos novos em `docs/verificacao/achados/`.
