## Passo executado
1. Correção de bug em produção (issue #534 e #531)

## O que foi feito
- Foi analisado o erro de -13.88% apontado na produção, que ocorria porque os dados fornecidos pelo yfinance / brapi para o Ibovespa estavam com fechamento absurdo na data anterior ou atual comparada, gerando uma grande variação inconsistente e falhando o teste do auditor (`ibov.variacao_plausivel`).
- O código em `app/collectors/ibovespa.py` foi alterado para validar se a variação percentual calculada (`var_pct`) excede os limites normais (acima de `12.0%` em módulo).
- Quando a variação exceder esse limite, o coletor emite erro no log e rejeita o dado (retorna `None`), evitando o envio de dados corrompidos para o banco de dados de produção.
- O achado do auditor em `docs/auditoria/achados/2026-10-26-ibov-variacao-implausivel.md` foi atualizado para status: `resolvido`.
