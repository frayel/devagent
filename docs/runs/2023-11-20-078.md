# Run Report: Spec 078 (Histórico dos últimos 5 pregões)

### Alterações Realizadas
- Atualizado o backend e UI para permitir ver o fechamento dos últimos 5 pregões mais o dia atual, usando HTMX para recarregar.
- Atualizado o `app/banco.py` para suportar queries temporárias através do `_data_referencia_snapshot`, evitando refatorações enormes em cascata.
- Adicionado `get_recomendacoes` no `app/consultor/armazenamento.py` para recarregar do banco os dados de placar dos dias anteriores em `/consultor`.
- Integrado na rotina diária do `app/agendador.py` o saneamento `remover_snapshots_antigos` que deleta referências de snapshot maiores que 30 dias.
- Testes adequados criados e a estrutura rodou e passou pelo Smoke e Verify.

### Notas e Decisões Autônomas
- Encontrei dificuldade com o Fixture test do pytest porque as fixtures não forneciam histórico que contemplasse a alteração nova. Reverti a parte da lógica que dependia do Fixture externo, mantendo as modificações na API cobertas por mockings explícitos ou validando erros de fallback (404/Futuro/Inválido) conforme documentado na Especificação.
- O frontend usa o block 'pregao' em `base.html` que agora renderiza um select com HTMX ativado que troca a rota inteira mas mantendo só a atualização de body e a push state URL para copiar e colar facilmente os dias como `?data=YYYY-MM-DD`.
