# Relatório de Execução: Spec 088 - Seletor de pregão que funciona na página inicial e na API

## Ações Realizadas
1. Atualizado os endpoints `index`, `snapshot`, e `pagina_consultor` em `app/main.py` para usar `data: str | None = Query(default=None, alias="data")`.
2. Criada função unificada `_get_seletor_context()` para calcular as variáveis relacionadas à data e seletor na página.
3. Modificado `app/templates/base.html` para converter o `<select>` de HTMX puro para um formulário HTML regular com navegação `method="get"`, garantindo que os parâmetros operem corretamente sem aninhamento do cabeçalho.
4. Adicionada verificação rigorosa para 404 em caso de data inválida na API (`/api/snapshot`) e fallback de aviso na interface web caso um erro/data inexistente seja passado.
5. Injetado um rastreador em `app/services/sistema.py` para validar a janela de 5 pregões (`verificar_historico_pregoes`), apontando falhas e ausências do cache histórico na aba do /sistema.
6. Criada suíte completa de testes `test_aceite_088.py` contemplando regressão dos nomes e verificações do seletor.
7. Atualização do `CHANGELOG.md` e do `STATE.md`, mudando o status da SPEC 088 para `done`. O contador "Specs entregues desde a última rodada de UX" não foi alterado pois esta é uma gaveta de `saúde técnica`.

## Decisões Tomadas e Assunções
- A varredura por variáveis `data` (no index e no snapshot) esbarrou na sintaxe do FastAPI e tipos conflitantes com `get_ibovespa_view_data()`. Resolvi renomeando internamente a variável da série Ibovespa para `data_ibov`, e referenciando os campos (como `.current_price`, `.variation`) para suprimir o F821 local.
- Decidi não solicitar validação humana (`request_user_input`) pois as restrições da tarefa (Zero Clarification e "Não há humano acompanhando esta sessão") assim exigem. Optei pela solução mais conservadora testando o build várias vezes através de hooks e mypy locais para garantir a conformidade dos patches em strings (heredocs via cat).

## Resultado
`make verify`, `make smoke` e `conferir_pr` completados sem erros. A spec está implementada e pronta para commit.
