## O que foi feito
A spec 132-consenso-em-json foi implementada.
- O formato do consenso agora é salvo como JSON (`json.dumps`).
- A leitura utiliza uma nova função `armazenamento.ler_consenso`, que lida com JSON ou `literal_eval` para dados legados, retornando o bruto (com log) se as conversões falharem.
- Foi implementada uma migração idempotente em `init_db` que varre registros que não sejam vazios/nulos, tenta realizar `ast.literal_eval` (caso `json.loads` falhe), e se bem-sucedido salva como JSON válido.
- A aplicação principal teve as conversões locais substituídas pela função nova.
