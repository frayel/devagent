# Relatório de Execução: Implementação da Spec 076b

## Decisão
Implementada a spec `docs/specs/076b-banco-migracao-lote-3-parte-b.md` (migração de painéis para snapshots - lote 3, parte b). Não foram realizadas tarefas de manutenção ou revisão de experiência porque esta spec faz parte da própria saúde técnica do projeto.

## Ações Realizadas
1. Modificadas as funções `save_*` e `get_latest_*` no `app/database.py` para as 7 tabelas especificadas, passando a ler/gravar de `snapshots_paineis`.
2. Removidos os comandos `CREATE TABLE` e `CREATE INDEX` relacionados do `init_db`.
3. Ajustado `tests/test_variacao_subita.py` para consultar `snapshots_paineis`.
4. Atualizada a documentação (`docs/context/arquitetura.md`, `docs/context/operacao.md`, `docs/skills/criar-coletor.md`) para refletir o Postgres como banco padrão via `app/banco.py`.
5. Spec 076b marcada como `done`.

## Retrospectiva
- Quando há testes que limpam e inserem tabelas individualmente (`DELETE FROM cache...`), eles também precisam ser adaptados para a nova estrutura baseada em `snapshots_paineis` para evitar `OperationalError: no such table` ao apagar essas tabelas extintas.
