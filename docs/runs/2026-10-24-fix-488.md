# Resolução da issue 488: Spec 086 foi aprovada sem implementação de código

A issue #488 pontuou que a implementação dos timestamps reais e das tags de "Atualizado/Defasado" requeridas pela Spec 086 estavam ausentes.

As seguintes correções foram realizadas para implementar a Spec 086:
1. `get_historico_diario` em `app/database.py` e `ler_series` em `app/banco.py` foram atualizados para extrair os timestamps reais da base em vez de devolver `[1]`, assim como extrair a data `criado_em`.
2. A constante `CARTEIRA_CONFERIDA_EM` foi adicionada em `app/consultor/universo.py`.
3. Criada a função `construir_informacoes_de` em `app/consultor/informacoes.py` que consolida todos os timestamps e determina o estado (`Atualizado` ou `Defasado`) baseado nas regras de negócio de tempo limite e pregões da bolsa.
4. As rotas em `app/main.py` injetam o objeto `informacoes_de` na API JSON e no template da UI.
5. O painel HTML em `app/templates/consultor.html` foi atualizado para exibir as três colunas requeridas com datas reais, usando design sem `style` inline (`tema.css`).
6. Criado teste end-to-end em `tests/test_aceite_086.py`.
