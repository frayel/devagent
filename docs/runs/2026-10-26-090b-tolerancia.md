# Relatório de Execução: Spec 090b - Tolerância a Símbolo Inválido

## Objetivo
Implementar a Spec 090b, que trata de isolar falhas de 404 de símbolos deslistados do Yahoo Finance durante as requisições em lote. Esses símbolos devem ser suspensos por 24 horas e alertados na página do sistema (status Yahoo).

## Ações Realizadas
- **`app/banco.py`**: Criada tabela `simbolos_sem_cotacao` e implementadas as funções `registrar_falha_simbolo`, `is_simbolo_suspenso` e `get_simbolos_suspensos`.
- **`app/database.py`**: Exportadas as funções de banco.
- **`app/services/sistema.py`**: Adicionada checagem para mostrar símbolos sem cotação sob o status do Yahoo Finance com severidade ATENÇÃO.
- **`app/collectors/utils.py`**: Adicionada lógica de "quebra" de lotes de requisição caso ocorra erro 404. O lote que apresenta falha é sucessivamente dividido (até 4 níveis) para isolar o símbolo ofensor, que então é registrado. Símbolos suspensos são filtrados antes da consulta.
- **`tests/test_aceite_090b.py`**: Testes de aceitação para validação de divisão de lote e suspensão de símbolos.
- **Arquivos de status**: `docs/STATE.md` e `CHANGELOG.md` atualizados.
- **Status da especificação**: `docs/specs/090b-tolerancia-a-simbolo-invalido.md` atualizado para `status: done`.

## Validação
- Os testes em `make verify` passaram sem regressão.
- `make smoke` operou perfeitamente.
- Script de disciplina de PR `python -m devagent.conferir_pr` retornou OK.

## Conclusão
Spec 090b entregue. PR com as modificações preparado.
