# Ciclo: Spec 073a

## Decisões
- Implementada a camada unificada de banco de dados (`app/banco.py`) conectando ao Postgres usando `psycopg` quando a variável `DATABASE_URL` estiver presente, com fallback para SQLite.
- A função de inicialização não é mais chamada em toda operação, mas uma única vez em `init_db()` usando um controle em memória.
- As chamadas `get_backend_type()` foram refatoradas para utilizar cache e não sofrer com a sobrecarga de testar a conexão no endpoint `/api/coleta`.
- Refatorado `app/consultor/armazenamento.py` para não usar duplicação da conexão.
- O fallback e a inicialização passam em `test_banco.py`.
