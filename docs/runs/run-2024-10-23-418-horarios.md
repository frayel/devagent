# Relatório de Execução - Auditoria #418: Painéis exibindo data/hora de forma incompleta no rodapé

## Contexto
O auditor reportou o achado `2026-10-23-paineis-fuso-horario-incompleto` (Issue #418) onde a data e hora eram exibidas de forma incompleta em alguns painéis, como `22/10 19:39 BRT` e `22:39 BRT`, o que viola a convenção em `PRODUTO.md` de usar datas completas (`dd/mm/aaaa`) e o fuso horário explícito (BRT).

## Análise e Implementação
- Foi identificado que nos arquivos `app/main.py`, `app/services/sistema.py`, `app/services/mare.py` e `app/templates/index.html` haviam formatações sendo feitas usando `.strftime("%d/%m %H:%M BRT")` ou apenas com a hora `.strftime("%H:%M")`.
- Foi realizada uma varredura para localizar todos os `.strftime` que formatavam as datas incompletas.
- O formato de data e hora foi padronizado para o esperado: `%d/%m/%Y %H:%M:%S BRT`.
- Adicionalmente, foi incluído um teste de regressão em `tests/test_aceite_auditoria_horarios.py` para garantir que o rodapé com datas seja sempre formatado com o ano (duas barras).
- As alterações foram passadas no ruff e mypy via `make verify`.

## Decisões
- O fallback para exibir somente as horas e minutos do sistema sem a data quando `com_data=False` em `app/services/sistema.py` foi modificado para exibir também os segundos.
- Adicionei um teste de regressão automatizado que faz o parsing do HTML buscando a div de rodape com o formato incorreto sem as duas barras da data.
