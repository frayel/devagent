# Execução Spec 077a

Implementada a especificação de manutenção para limpeza dos últimos resíduos do SQLite efêmero para o Postgres.

## Alterações realizadas
1. `app/services/consultor_opinioes.py` e `app/consultor/armazenamento.py`:
   - Foi construída a função `sql_para` para que as _queries_ identifiquem a sintaxe correta (placeholders `?` ou `%s`) baseada no `backend`.
   - Adicionada a instrução para a criação da tabela `consultor_llm_uso` caso seja instanciado o Postgres.
2. `app/database.py` e `app/banco.py`:
   - A função `diagnostico()` foi refatorada e migrada para a abstração `app/banco.py`, capturando as métricas adequadas (`pg_database_size`) quando em conexão com o Neon/Postgres.
   - Foram removidas do `init_db` as criações de tabelas para `radar_anomalia_fechamento_cache` e `consultor_confianca_regras`.
   - Modificamos os caches pendentes destas tabelas para o uso com o mecanismo de snapshot através do uso de `_ler_snapshot_completo()`.

Foi efetuada a verificação final (`make verify` e `make smoke`) que acusaram sucesso de _check_.
Nenhum incremento no contador de _specs entregues_ no estado, visto tratar-se de spec na gaveta "saúde técnica".
