## O que foi feito
1. O coletor `anomalia_peso` usava a estrutura de JSON para os dados retornados pela API `/spark` do Yahoo Finance que assumia sempre uma chave `"spark"`. A resposta, às vezes ou agora, mudou para retornar as chaves (ex: `VALE3.SA`) na raiz. Corrigimos `app/collectors/anomalia_peso.py` para iterar tanto se tiver a chave `"spark"`, quanto se houver os símbolos diretamente na raiz. Também adicionamos um teste flexível que reflete o novo formato da API em `tests/test_anomalia_peso.py`.
2. A API `/api/snapshot` não incluía `coletado_em` e `fonte` (ou incluía como `time`) para os painéis `divergencia_ibov_dolar`, `sensibilidade_juros` e `correlacao_di` em `app/main.py` e `app/services/correlacao_di.py`, quebrando o contrato de auditoria reportado na issue `#562`. Corrigimos isso mapeando essas chaves corretamente nesses painéis, mantendo retrocompatibilidade no layout e nas chamadas, mas atualizando a saída no /api/snapshot.
