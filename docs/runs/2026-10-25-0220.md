# Revisão de Especificação: docs/specs/095-testes-sem-rede.md

**Raia:** Revisor
**Alvo:** `docs/specs/095-testes-sem-rede.md`

## O que foi conferido

1. O problema: testes estão usando a rede (`httpx.get` ao invés de `requests.get`, como mencionado na spec - ajustaremos a spec).
2. Tamanho: o impacto de bloquear conexões com mock global e ajustar alguns mocks é pequeno e cabe em uma sessão.
3. Testes sem rede: critério claro de mock em sockets, requests, httpx.
4. Compatibilidade: a spec menciona `requests.get` mas o código usa predominantemente `httpx.get`. O coletor `consultor_opinioes` usa `httpx.get`, não `requests.get`. A spec foi ajustada para citar `httpx.get` ou a API real que está em uso.

## O que foi alterado

1. Troquei menções a `requests.get` por `httpx.get` na spec, visto que a aplicação não possui `requests` em seus `requirements.txt` e usa `httpx`. O teste de verificação no critério de aceite também passará a referenciar `httpx.get`.
2. Adicionei o cabeçalho `revisada: 2026-10-25`.
